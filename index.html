2.2 Multiplicación de matrices y vectores

La neurona como producto punto

Una versión mínima de una neurona:

\[z=\mathbf{x}^{\top}\mathbf{w}+b\]

x = np.array([0.8, 0.3, 0.5])
w = np.array([1.2,-0.7, 0.4])

z = x @ w

El producto punto combina características con pesos.

De una observación a un batch

\[ X\in\mathbb{R}^{m\times n},\quad W\in\mathbb{R}^{n\times p} \]

\[ Z=XW\in\mathbb{R}^{m\times p} \]

32 ejemplos × 784 píxeles
          @
784 entradas × 10 clases
          =
32 ejemplos × 10 scores

MNIST como una capa lineal

X_batch = x_train[:32].reshape(32, -1) / 255.0
W = np.random.randn(784, 10) * 0.01

logits = X_batch @ W
print(logits.shape)
# (32, 10)
imagen
28×28
→
flatten
784
→
matmul
784×10
→
10 scores

Tres propiedades para recordar

  • Distributiva: \(A(B+C)=AB+AC\)
  • Asociativa: \(A(BC)=(AB)C\)
  • No conmutativa: normalmente \(AB\neq BA\)

Producto elemento a elemento ≠ producto matricial

A * B   # Hadamard / element-wise
A @ B   # matrix multiplication

2.3 Matrices identidad e inversa

Identidad: el “1” de las matrices

\[AI=A\]

I = np.eye(3)
[[1,0,0],
 [0,1,0],
 [0,0,1]]

Inversa: deshacer una transformación

Si \(A^{-1}\) existe:

\[A^{-1}A=I\]

Para resolver:

\[Ax=b\]

podemos pensar en:

\[x=A^{-1}b\]

En código numérico, suele ser preferible:

x = np.linalg.solve(A, b)

¿Por qué una matriz puede no tener inversa?

S = [[1,2],
     [2,4]]

La segunda fila no aporta una dirección nueva.

  • determinante = 0
  • rango insuficiente
  • información lineal redundante

2.4 Dependencia lineal y span

¿Qué significa “dependencia”?

Si:

\[v_2=2v_1\]

entonces \(v_2\) no agrega una dirección nueva.

v1 = np.array([1.,2.])
v2 = np.array([2.,4.])
A  = np.column_stack([v1,v2])

np.linalg.matrix_rank(A)
# 1

Span: el espacio alcanzable

El span es el conjunto de todas las combinaciones lineales:

\[a_1v_1+a_2v_2+\cdots+a_kv_k\]

1 dirección independiente
→
una línea
2 direcciones independientes
→
un plano

En datos: característica redundante

x1 = np.random.randn(200)
x2 = 3*x1
x3 = np.random.randn(200)

X = np.column_stack([x1,x2,x3])

X.shape[1]                # 3 columnas
np.linalg.matrix_rank(X)  # rango 2

Tenemos tres columnas, pero solo dos direcciones de información lineal.

2.5 Normas

Norma = una forma de medir magnitud

Para un vector \(x\):

\[\|x\|_p=\left(\sum_i |x_i|^p\right)^{1/p}\]

En ML aparecen especialmente:

  • \(L^1\): suma de valores absolutos
  • \(L^2\): distancia euclidiana
  • \(L^\infty\): mayor valor absoluto
  • Frobenius: extensión útil para matrices

L1 y L2 con un ejemplo

x = np.array([3., -4., 2.])

np.linalg.norm(x, 1)  # L1
np.linalg.norm(x, 2)  # L2

\(L^1\)

“¿Cuánto suman todos los desplazamientos?”

\(L^2\)

“¿Cuál es la distancia directa?”

Distancia entre imágenes MNIST

a = x_train[0] / 255.0
b = x_train[1] / 255.0

d = np.linalg.norm((a-b).ravel(), 2)

Uso conceptual: comparar qué tan “lejos” están dos objetos en un espacio numérico.

En ML, la elección de distancia cambia qué significa similar.

Normas y regularización

Una penalización sobre los pesos puede controlar complejidad:

\[\text{loss total}=\text{loss datos}+\lambda\|w\|\]

  • L1 → favorece soluciones más dispersas
  • L2 → desalienta pesos muy grandes

2.7 Eigendecomposition

Autovector: una dirección que sobrevive a la transformación

\[Av=\lambda v\]

  • \(v\) = autovector → dirección especial
  • \(\lambda\) = autovalor → cuánto se estira/contrae esa dirección

La transformación cambia la magnitud, no la dirección del autovector.

Un ejemplo numérico

A = np.array([[3.,1.],
              [0.,2.]])

values, vectors = np.linalg.eig(A)

Verificación:

A @ v ≈ lambda_ * v

La conexión importante: covarianza

Para una nube de datos, la matriz de covarianza resume cómo varían juntas las variables.

Sus autovectores indican direcciones importantes y sus autovalores cuantifican la variación en esas direcciones.

datos
→
covarianza
→
eigenvectors
→
direcciones principales

2.8 Singular Value Decomposition (SVD)

SVD: descomponer para entender

\[A=U\Sigma V^T\]

La ventaja práctica:

SVD existe para cualquier matriz real, incluso cuando no es cuadrada.

  • \(U\) → direcciones del espacio de salida
  • \(\Sigma\) → valores singulares, importancia relativa
  • \(V\) → direcciones del espacio de entrada

SVD como compresión

Si conservamos solo los \(k\) valores singulares más importantes:

\[A\approx U_k\Sigma_kV_k^T\]

matriz original
→
SVD
→
top-k componentes
→
aproximación

MNIST: reconstrucción de bajo rango

U, s, Vt = np.linalg.svd(img, full_matrices=False)

k = 5
img_k = (U[:,:k] * s[:k]) @ Vt[:k,:]

Probar en Colab:

k = 1 → estructura muy básica
k = 5 → dígito reconocible
k = 20 → reconstrucción cercana

Conexión moderna

La idea de representar un objeto grande mediante una estructura de menor rango aparece en:

  • compresión
  • reducción de parámetros
  • aproximaciones de matrices
  • adaptación eficiente de modelos

2.9 Pseudoinversa de Moore–Penrose

Cuando \(A^{-1}\) no existe o no aplica

Para matrices rectangulares usamos la pseudoinversa:

\[A^+\]

A_plus = np.linalg.pinv(A)
x = A_plus @ y

Puede producir:

  • solución de norma mínima, si hay muchas soluciones
  • mejor aproximación de mínimos cuadrados, si no hay solución exacta

Ejemplo: regresión lineal

A = np.column_stack([np.ones(n), x])
beta = np.linalg.pinv(A) @ y

2.10 Operador traza

Traza = suma de la diagonal

\[\operatorname{Tr}(A)=\sum_i A_{i,i}\]

np.trace(A)

Una identidad útil:

\[\|A\|_F=\sqrt{\operatorname{Tr}(AA^T)}\]

¿Por qué importa?

La traza permite escribir de forma compacta expresiones de:

  • normas
  • varianza y covarianza
  • derivaciones matriciales
  • objetivos de optimización

Propiedad útil:

\[\operatorname{Tr}(AB)=\operatorname{Tr}(BA)\]

cuando las dimensiones permiten ambos productos.

2.11 Determinante

Determinante = factor de cambio de volumen

Para una transformación lineal \(A\):

  • \(|\det(A)|>1\) → expande volumen
  • \(0<|\det(A)|<1\) → contrae volumen
  • \(\det(A)=0\) → colapsa al menos una dimensión
np.linalg.det(A)

El caso singular

A = [[1,2],
     [2,4]]

\[\det(A)=0\]

La transformación aplasta un plano sobre una línea.

Eso conecta con:

  • no invertibilidad
  • dependencia lineal
  • rango insuficiente

2.12 Ejemplo: Principal Components Analysis (PCA)

El problema de PCA

Tenemos datos con muchas dimensiones y queremos una representación más compacta que pierda la menor información posible.

784 píxeles
→
PCA
→
20 componentes
→
reconstrucción

PCA en una frase

Encuentra nuevas direcciones ortogonales ordenadas por cuánta variación explican.

Conceptualmente:

  1. centrar los datos
  2. medir covarianza
  3. encontrar direcciones principales
  4. ordenar por importancia
  5. proyectar a menos dimensiones

MNIST: 784 → 2

X = x_train[:5000].reshape(5000, -1) / 255.0

pca = PCA(n_components=2)
Z = pca.fit_transform(X)

print(Z.shape)
# (5000, 2)

Ahora podemos visualizar en un plano datos que originalmente tenían 784 dimensiones.

MNIST: 784 → 20 → 784

pca20 = PCA(n_components=20)
Z20   = pca20.fit_transform(X)
X_rec = pca20.inverse_transform(Z20)

Preguntas para el grupo:

  • ¿el dígito sigue siendo reconocible?
  • ¿cuánto se redujo la representación?
  • ¿qué información se perdió?

Laboratorio transversal: CPU, GPU y frameworks

El álgebra no cambia; cambia dónde se ejecuta

               misma operación
                    A @ B
                      │
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
      NumPy      TensorFlow      PyTorch
       CPU        CPU / GPU       CPU / GPU

TensorFlow: dispositivo administrado por el runtime

A_tf = tf.constant(A)
B_tf = tf.constant(B)
C_tf = tf.matmul(A_tf, B_tf)

print(C_tf.device)

PyTorch: movimiento explícito

device = "cuda" if torch.cuda.is_available() else "cpu"

A_t = torch.from_numpy(A).to(device)
B_t = torch.from_numpy(B).to(device)
C_t = A_t @ B_t

Para comprender GPU, primero comprender shape + operación + dispositivo.
